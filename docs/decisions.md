- Сохранение и поиск Email будет происходить с предварительным приведением данных к нижнему регистру.
    - В ходе работы с миграцией было принято решение поменять тип Email на citext, чтобы избежать ошибки пропустить приведение к нижнему регистру в коде. Необходимость приводить Email к нижнему регистру в коде программы отпала.
- Справочники по типу ролей и статусов будут существовать в базе данных как отдельные сущности со своим ID (int без автоинкримента).
- На всех связях был установлен параметр удаления Restrict, чтобы избежать каскадного удаления родительских элементов.
- Для удобства именования в стиле snake_case был использован пакет EFCore.NamingConventions.
