### 06.11.26 | Email разного регистра
Email будет храниться в базе данных с типом citext. Такое решение было принято для избежания ошибок, связанных с записью одной и той же почты разными регистрами.
### 06.11.26 | Хранение справочников
Справочники по типу ролей и статусов будут существовать в базе данных как отдельные сущности со своим ID (int без автоинкремента). Альтернатива была в использовании enum, но это могло вызвать неудобства из-за разного расположения данных.
### 06.11.26 | Удаление связанных объектов
На всех связях был установлен параметр удаления Restrict, чтобы избежать каскадного удаления родительских элементов.
### 06.11.26 | Разные стили именования
Для удобства именования таблиц в базе данных в стиле snake_case был использован пакет EFCore.NamingConventions.
